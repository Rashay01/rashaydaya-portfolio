# Security Policy

## Reporting a vulnerability

Please report security issues in this site (rashaydaya.co.za) privately through
GitHub: **[Report a vulnerability](https://github.com/Rashay01/rashaydaya-portfolio/security/advisories/new)**.

Please don't open a public issue for security problems.

Include what you found, where (URL or file), and steps to reproduce. You'll get
a reply as soon as I can, and credit in the fix if you want it.

## Scope

- In scope: rashaydaya.co.za and the code in this repository, including the
  contact form API (`/api/contact`).
- Out of scope: denial-of-service, automated scanner output without a working
  proof of concept, and missing headers with no demonstrable impact.
