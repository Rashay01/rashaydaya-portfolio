# Product

## Register

brand

## Users

Technical recruiters, hiring managers, and senior engineers reviewing candidates. They arrive from LinkedIn, job applications, or direct referrals. Primary context: desktop review during a hiring process; occasional mobile glance on first contact. They need to assess capability and credibility fast — not read a blog.

## Product Purpose

A personal portfolio for Rashay Daya, DevOps Engineer and Full Stack Builder. The site must prove technical depth and operational credibility — not just list technologies. Success: a recruiter spending more than 90 seconds, a hiring manager referencing a specific project, an engineer wanting to collaborate.

## Brand Personality

Precise, quiet, operational. Three words: **austere · credible · alive**.

The voice is the systems it represents: reliable infrastructure, clean output, no noise. Not humble, not loud — confident in what it doesn't need to say.

## Anti-references

Generic developer portfolios with purple gradient hero sections and infinite-scroll animations. Overbuilt React showcases that flex JavaScript at the cost of the actual work. Bootstrap-era grid templates. Anything that looks like it was assembled from a Dribbble kit.

Dark mode with neon accents, glassmorphism cards used decoratively, floating-particle hero scenes, rainbow gradient text, the hero-metric-grid SaaS template.

## Design Principles

1. **Precision over decoration.** Every visual element earns its place. If it doesn't carry information or establish credibility, it goes.
2. **The work is the signal.** Projects and metrics speak louder than superlatives. Typography and layout amplify, never compete.
3. **Operational confidence.** The interface feels like it runs in production — not like a demo. Subtle motion, real data, live status.
4. **Dark by necessity, not fashion.** The obsidian palette exists because this is a systems engineer's environment. Not trend.
5. **The terminal aesthetic is earned.** Monospace type and console patterns appear because they are native to the discipline, not deployed as decoration.

## Accessibility & Inclusion

WCAG AA minimum. Focus states: filament orange outline, 2px offset. Reduced-motion respected. Sufficient contrast on all text/background combinations.
